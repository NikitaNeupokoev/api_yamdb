# YaMDb: Платформа для отзывов о произведениях

YaMDb - это платформа, предназначенная для сбора отзывов пользователей о различных произведениях. В отличие от платформ потокового вещания или онлайн-магазинов, YaMDb не предоставляет доступ к самим произведениям (фильмам, музыке, книгам и т.д.).  Основная цель YaMDb - предоставить пользователям возможность делиться своим мнением и оценками о произведениях, а также формировать рейтинг на основе этих оценок.

## Основные возможности

*   **Категории произведений:** Произведения классифицируются по категориям (например, «Книги», «Фильмы», «Музыка»).
*   **Жанры произведений:** Произведения могут быть отнесены к нескольким жанрам (например, «Сказка», «Рок», «Артхаус»).
*   **Отзывы пользователей:** Аутентифицированные пользователи могут оставлять текстовые отзывы и оценки (от 1 до 10) к произведениям.
*   **Рейтинг произведений:** На основе пользовательских оценок формируется средний рейтинг произведения.
*   **Комментарии к отзывам:** Пользователи могут комментировать отзывы других пользователей.
*   **Разграничение прав доступа:**
    *   Добавление произведений, категорий и жанров: Только администраторы.
    *   Добавление отзывов, комментариев и оценок: Только аутентифицированные пользователи.
    *   Просмотр списка произведений, категорий и жанров: Доступно всем.

## Аутентификация и авторизация

В YaMDb реализована система аутентификации на основе JWT (JSON Web Token).

### Регистрация нового пользователя

1.  **Отправка запроса на регистрацию:**  Пользователь отправляет `POST`-запрос с параметрами `email` и `username` на эндпоинт `/api/v1/auth/signup/`.
2.  **Получение кода подтверждения:** YaMDb отправляет письмо с кодом подтверждения (`confirmation_code`) на указанный адрес `email`.
3.  **Получение токена:** Пользователь отправляет `POST`-запрос с параметрами `username` и `confirmation_code` на эндпоинт `/api/v1/auth/token/`. В ответе на запрос пользователь получает `token` (JWT-токен).

После успешной регистрации и получения токена, пользователь может использовать его для доступа к защищенным ресурсам API.  Токен необходимо передавать с каждым запросом.

### Редактирование профиля пользователя

После получения токена пользователь может отправить `PATCH`-запрос на эндпоинт `/api/v1/users/me/` и заполнить или изменить поля в своём профиле.  (Описание доступных полей можно найти в документации API).

### Создание пользователя администратором

Администраторы могут создавать новых пользователей через административную панель Django или отправляя `POST`-запрос на эндпоинт `/api/v1/users/`.

*   **Важно:**  При создании пользователя администратором, пользователю **не** отправляется письмо с кодом подтверждения автоматически.
*   **Получение токена после создания администратором:** Пользователь, созданный администратором, должен самостоятельно отправить `email` и `username` на эндпоинт `/api/v1/auth/signup/`, чтобы получить письмо с кодом подтверждения, а затем запросить токен, как описано в процессе обычной регистрации.

## Связанные данные и каскадное удаление

Для обеспечения целостности данных в YaMDb реализованы следующие правила каскадного удаления:

*   При удалении пользователя (`User`):
    *   Удаляются все отзывы (`Review`) и комментарии (`Comment`), принадлежащие этому пользователю.
*   При удалении произведения (`Title`):
    *   Удаляются все отзывы (`Review`), связанные с этим произведением, и все комментарии (`Comment`) к этим отзывам.
*   При удалении отзыва (`Review`):
    *   Удаляются все комментарии (`Comment`), связанные с этим отзывом.
*   При удалении категории (`Category`) или жанра (`Genre`):
    *   **Не** удаляются связанные произведения (`Title`).  Связь между произведением и категорией/жанром просто разрывается.

## Установка

Следуйте этим инструкциям для установки и запуска проекта YaMDb.

1.  **Клонирование репозитория:**

    ```bash
    git clone https://github.com/NikitaNeupokoev/api_yamdb.git
    cd api_yamdb
    ```

2.  **Создание и активация виртуального окружения:**

    ```bash
    # Создание для Linux/macOS
    python3 -m venv venv

    # Создание для Windows
    python -m venv venv

    # Активация для Linux/macOS
    source venv/bin/activate

    # Активация для Windows
    venv\Scripts\activate
    ```

3.  **Обновление pip (рекомендуется):**

    ```bash
    python -m pip install --upgrade pip
    ```

4.  **Установка зависимостей:**

    ```bash
    pip install -r requirements.txt
    ```

5.  **Применение миграций:**

    ```bash
    # Переходим в папку с manage.py
    cd api_yamdb

    python manage.py migrate
    ```

6.  **Запуск сервера:**

    ```bash
    python manage.py runserver
    ```

Сервер будет запущен по адресу `http://127.0.0.1:8000/`.
